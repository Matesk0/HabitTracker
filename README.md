# Habit & Day Tracker (Expo Go Mobile App)

A minimalist iOS-widget-styled mobile habit tracker and year progress app built with React Native and Expo Go, inspired by `image.png`.

## 📱 Widgets Included

1. **Widget 1 (Quick Check-In)**: One-tap toggle button for today's selected habit with streak counter and visual feedback.
2. **Widget 2 (30-Day Tracker)**: Interactive 30-day dot matrix for the selected habit. Tap any day cell to toggle completion and track completion rate.
3. **Widget 3 (Full Year Progress)**: Exact replica of the 19-column dot grid from `image.png` representing all 365/366 days, highlighting days passed, live current day indicator, and days remaining.

## 🚀 How to Run with Expo Go

### Prerequisites
- Install **Node.js**
- Install the **Expo Go** app on your iOS or Android phone from the App Store or Google Play Store.

### Start the App
```bash
npm install
npx expo start
```

- **iOS / Android**: Scan the QR code displayed in your terminal with your phone's camera (iOS) or the Expo Go app (Android).
- **Web**: Press `w` in the terminal to view in your web browser.
